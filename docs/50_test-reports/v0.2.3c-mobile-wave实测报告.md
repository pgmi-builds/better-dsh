## 一、变更清单

1. **手势状态输入只认官方面**（红线落地；起因：旧实现读第三方 Better Sidebar 的 `body[data-dsh-sidebar-collapsed]`，插件移除后属性恒缺 → `readRightOpen` 永真 → 状态机整体毒死）：
   - 左栏：动作 `ctx.layout.toggleSidebar()`；状态读 AppFrame `[data-sidebar-collapsed]`。
   - 右栏（0.1.5 ui-sidebar-right）：开 = 官方控件 `[data-sidebar-right-expand]`（会话头角落），关 = `[data-sidebar-right-toggle]`（dock chrome）；状态读双 facet：`fullscreen = [data-rightbar-fullscreen] 在场`，`trackless = [data-rightbar-collapsed] 在场`，`readRightOpen = fullscreen || !trackless`。
2. **响应式零自设像素阈值**：CSS 规则键纯 `[data-sidebar-collapsed]`（无 @media），上游 auto-collapse 收 rail（今日 56px）时我们压成 0px，上游改阈值自动跟随；手势激活 band = 粗指针（`pointer: coarse`）∨ 任一面板窄态，细指针全静息。
3. **`mobile.breakpoint` 配置删除**（schema + boot payload + client 三处）；zoomGuard 内部 768 兜底不动。所谓"mobile 配置卡"从未存在（client 半唯一设置行是 failover）。
4. **0.1.5-rc.2 对齐移植**（随批发布）：persistence seam `inspect`→`stat`+`open(id,'read')`+`handle.read()`（`src/url-schema/handlers/agent.ts` `persistedEventsOf`）；`subagents.sendMessage` 统一 seam（下行 child / 上行 `parentSession`，`src/bridges/index.ts`、`src/subagents-surface.ts`）；session 事件名 `tool/code-dispatch(-start)` → `tool/ptc-dispatch(-start)`（`src/index.ts`，载波 `tools/ptc-dispatch-log` 名不变）。
5. **船货卫生**（本次新增 `dashr/scripts/copy-docs.mjs` 替换裸 `cpSync` prebuild）：发布 docs 副本排除 `60_exploration-and-research/`（gitignore 明文 never publish）、`superd/`、`dsh-sys-prompt_*.md`、`*_artifacts/`（2.8MB 探针产物），并对副本内 .md 做 `token=<20+字面量>` 脱敏。**事实记录（2026-09-11 全版本扫描）**：泄漏机制 = prebuild `cpSync('../docs','docs')` 把仓库根 docs 全量拷进包内再随 `files:["docs"]` 打包（docs:// URL schema 的运行时供给面，v0.1.8d 起存在）；包内镜像 `dashr/docs/` 被 `dashr/.gitignore` 的 `/docs/` 忽略 → git 永远看不见，2026-09-03 "never publish" 裁决只落了 git 轴，npm 轴漏网。受影响版本（registry 不可撤）：0.2.2-a(6 文件) / 0.2.2-b(8) / 0.2.2-c(33) / 0.2.3 游离(6) / 0.2.3-b(48 + superd 4)。**内容定级复核：全部 `token=` 命中均为占位符（`token=…` / `token=«redacted»`），真实 token 字面量从未上过 registry**——泄漏内容 = 研究笔记 + superd 蓝图 + 测试报告，无凭据类材料。0.2.3-c tarball 70 文件 / 757KB，敏感扫描零命中。
