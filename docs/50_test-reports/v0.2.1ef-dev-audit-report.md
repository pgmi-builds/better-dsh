## 0. 一句话结论

**✅ 合规** —— 两个 change 的全部代码与声明式 patch 都落在 `@pgmi-builds/better-dsh` 包内随 npm 发布；四条官方扩展面（bundle patch 行 / 公开事件 / `dsh.client` 声明 / CSS·slot 注入）各就各位；upstream checkout 除 AGENTS.md 早已存档的环境级 patch 外**零改动**。唯一待办是把 0.2.1f 部署上 prod，让手改 patch 退役从「机制可行」变成「事实发生」。

## 7. 结论

原则守住了：**所有 change 的代码与声明式 patch 都在 `@pgmi-builds/better-dsh` 包内随 npm 发布**——

- kernel 供给三级（postinstall / spin-up / lazy）全在插件领地，venv + uv-cache 落包内；

- upstream checkout 除既有环境 patch 外零改动。

alpha.3 时代「升级即丢」的手改源码模式已在机制层面终结；剩余动作仅为一次版本化部署。
