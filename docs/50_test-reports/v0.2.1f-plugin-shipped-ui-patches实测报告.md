## 2. 实现面（代码清单）

- `dashr/cordis.patch.yml`：+`connection` 行覆盖（整行重述 + `trustedHosts: !!js (env).split(/\s+/).filter(Boolean).concat(ctx.webRuntime.trustedHosts)`；⚠ `!!js` 是 scalar tag，表达式不能以 `[` 开头——flow-seq 会被 yaml 拒）。
- `dashr/src/web-trust.ts`（新，host 半）：`buildBootScript` 纯函数 + `installWebTrust`（`webserver/index-inject` 监听，emit 时新鲜读 config）。一个内联 head script 双效：trusted hostname → `window.__DSH_TRANSPORT__={ownsHost:true}`（无 fetch/openStream，唯一效应 = isLoopback 翻真；不覆盖已有 transport）；mobile 阈值 → `window.__DASHR_MOBILE__`。
- `dashr/src/mobile/gesture.ts`（新，纯）：`isRecognizedSwipe`（起点∧距离∧速率 + 横向占优 + touch/pen only）、`isInteractiveOrigin`、`isNarrowViewport`、`resolveMobileConfig`。
- `dashr/src/mobile/client/index.ts`（新，client 半）：`setupMobileLayout`——`<style data-plugin data-plugin-css>` 注入（媒体查询 + `[data-sidebar-collapsed]` + `!important` 覆盖内联 grid template → 侧栏轨 0）+ document 级 pointer 监听 → `ctx.layout.toggleSidebar()`（窄视口=翻 narrowExpanded）。
- `dashr/src/index.ts`：Config + `trustedPageAuthorities` / `mobile`（schema 默认 enabled）；apply 挂 `installWebTrust`。
- `dashr/src/failover/client/index.ts`：client 入口挂 `setupMobileLayout`；package.json `dsh.client.inject` + `@deepseek-ai/dsh-client-ui-layout`（模块表边）。
- tsconfig exclude + `src/mobile/client`（沿 failover/client 的 client 半约定）。

## 3. 病因与定性回执（P2 复诊闭环）

- prod 消息 `…failed: settings are unavailable in this browser` = 浏览器侧 `isLoopback` 门（`ui-settings` memory 持久化终态不可用），非服务端 fence。
- 上游定性（设计笔记实证）：有意 = "非 loopback 关 Host 持久化（偏好进程本地、页面照常）"；无人设计 = mirror 把 memory 做成终态不可用 + trustedHosts 未传导到 host facts——当年源码 patch 存在的全部理由。
- B 机制恢复的正是设计意图形态（remote 页面照常 + Host 持久化）。

## 4. 验证环境事实

- 4999：systemd-run `dsh-4999-test`，`DSH_TRUSTED_HOSTS=probe.example`；profile patch 覆盖 `dashr-repl` 行 `trustedPageAuthorities: ['probe.example','192.168.31.130']`（+ 重述 python 表达式）。

- 旋钮惰性双态：无 env / 无 authorities 时 fence 与 boot script 均与原生一致（T3 + `buildBootScript` 空态 undefined 单测）。
