- **源码**（`src/index.ts:1099-1118`）：`ctx.systemPrompt.context({ name: 'dashr:escalation-guidance', order: ESCALATION_GUIDANCE_ORDER = 116, text })`；text 为 use-time 求值——`sandboxPolicy?.resolve({ session: context.agent?.session })`，`mode === 'workspace-write'` 返回注入文本，否则空串；service 缺失 / 无 agent 时 fail-closed（空串）。注册处注释注明依赖 upstream CONTEXT_ORDERS（110/115/120）。
- **模式矩阵测试**（`test/presentation.spec.ts:208-281`，v0.2.1b model-surface contracts）：order 116 在位 / workspace-write 注入 / read-only、danger-full-access 空 / 无 sandboxPolicy service 空——套件全绿。
- **本会话 runtime-context 快照（第一人称实测）**——当前为 workspace-write 模式，快照逐行：

  ```
  Current DSH file policy: workspace-write. Any available operation enforced by the
  DSH file sandbox may modify files under the session workspace: "/home/u1/workspaces/dashr". …

  Approval policy: ask. Operations that require approval may ask through the configured
  answerers; without an available answerer, the request fails closed.
  ```
