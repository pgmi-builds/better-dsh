# Glossary — dsh-dev-skill

Alphabetical key terms. Format: **Term** — definition (Ch N).

- **Activation** — process-local period a continuable child Agent is resident; one per live child Session (Ch 14)
- **asOfSeq** — snapshot watermark: seq of the last event a projection value reflects; −1 = empty log (Ch 16)
- **BlockAssembler** — shared fold turning a `StreamChunk` stream back into `ContentBlock`s; reassembly is never each adapter's job (Ch 17)
- **Bundle** — distribution format for Cordis config rows + code (`dsh.bundle` manifest); stays patchable by layers above (Ch 6)
- **Capability seam** — swappable capability with three mandatory roles: Service Definition, Provider, Consumer (Ch 7)
- **Compat block** — per-provider request-shape corrections in settings (`supportsDeveloperRole`, `maxTokensField`, `thinkingFormat`) (Ch 1)
- **ConfinedArgv** — wrapped argv + enforcement fact, denialSignatures, runnerFailureRules returned by `ctx.sandbox.confine` (Ch 15)
- **Continuable child** — durable child Session with optional live Activation; steerable/resumable, unlike one-shot SubagentRun (Ch 14)
- **Declaration merging** — TS-only augmentation of the Cordis `Context`/`Events` interfaces; how plugins extend event maps (Ch 4)
- **Derived history** — model transcript is folded from the session log (`deriveMessages()`), never stored separately (Ch 13)
- **DomainSpec / defineDomain** — typed plugin persistence spec (zod, layout, compatibleVersions) opened via `storageDomain.open` (Ch 16)
- **EpochHeader** — logged request state (config+system+tools) reconstructed from the latest `request/header` snapshot (Ch 13)
- **Execution world** — fs + subprocess + sandbox move together on one provider swap (Ch 7)
- **Fiber** — per-plugin runtime lifecycle instance (PENDING→LOADING→ACTIVE→…); the unit the registry loads/reloads (Ch 4)
- **Fail-closed approval** — `approval/request` waterfall; absent or unanswerable asker = deny, never silent allow (Ch 7, 15)
- **finalizeContent** — ToolDefinition-owned last content-only invariant run on a snapshotted result (Ch 8)
- **FsObservation** — present@version / absent record per owner session; drives guarded write/edit decisions (Ch 15)
- **InboxTarget** — `'next-turn' | 'next-step'` pending-message lists steering the agent loop (Ch 13)
- **inheritedEventCount** — exact fork-inherited prefix length stored beside the fork header (Ch 16)
- **inject** — hard service requirements on a plugin; entries start concurrently, ordering comes from inject not YAML position (Ch 4)
- **InvariantInstaller** — package-attributed check bundle run in a dedicated child fiber via `ctx.invariants` (Ch 13)
- **isolate** — Context scope label; service visibility is ancestor/isolate only — sibling shadowing does not exist (Ch 5)
- **Layer order** — bundles (listed order) → profile patch → home patch → `--patch` argv; later layers win by whole-row restatement (Ch 2, 6)
- **Live-preferred corpus** — session query prefers live `ctx.sessions`, falls back to persisted logs (Ch 16)
- **LlmAdapter** — abstract provider contract: `stream()` emits `StreamChunk`s; one adapter call = one attempt (Ch 3, 17)
- **LlmError** — stable-code error type; preserved by the agent loop; use for UNSUPPORTED_OPTION etc. (Ch 3, 17)
- **Monotonic guard** — deny-or-abstain check with protected identity, registered after pre-execute allow, before execute; can never force-allow (Ch 8, 15)
- **Peer dependency** — requirement for the host's shared service instance; bundling your own copy breaks identity (Ch 8)
- **Persist-before-event** — attachments are durable before the owning session event is appended (Ch 16)
- **PreToolDecision** — allow | deny(reason) | ask from `tools/pre-execute`; only `allowed-once` approval grants (Ch 15)
- **Profile** — named composition in harness home listing bundles + user `cordis.patch.yml` (`web`, `headless`, `sdk`, `sdk-minimal`, `acp`) (Ch 6)
- **ProjectionDefinition** — pure synchronous per-session state unit the projection registry drives, backfolds, and checkpoints (Ch 16)
- **Remote controller** — API controller projecting a seam onto the Remote namespace; redaction/refusal live there (Ch 7)
- **RemoteResult<T>** — client-remote result discriminated by `code`, never rejected; branch `if(!result.ok)` (Ch 19)
- **Rescope** — vendored Cordis published as `@deepseek-ai/*` to avoid squatting upstream registry names (Ch 6)
- **Reserved transport** — `run_code` (`ptc`/`both`): only wire-contribution tool, excluded from filterable layers (Ch 11)
- **Revision token** — opaque settings/storage stat token; equal ⇒ unchanged, unequal promises nothing (Ch 16)
- **SandboxMode** — default `read-only`; escalation is one-shot, strictly wider, needs justification (Ch 10, 15)
- **session/end-seed** — constructor-only marker separating fork-inherited seed history from live work (Ch 12, 13)
- **SessionEvent / SessionEventMap** — typed append-only log entry `{type, seq, time, data}`; vocabulary is merge-extensible (Ch 12)
- **SettingsDescriptor** — `{ns, schema, value, revision, base, user, applies}` with mandatory `redactSecrets` on wire (Ch 18)
- **Shadow price** — compaction metering: `shadowedRange`/`shadowedSeqs`/`shadowedTokenCount` on the replace op (Ch 12)
- **Slot cardinality / priority** — single/list/keyed/chain dispatch axis; lower priority renders first; cell-id reuse = replacement (Ch 18)
- **SpillRef** — `{locator, bytes, retrievalHint}` for tool text exceeding inline budget; locator opaque (Ch 14)
- **Step / Turn** — step = one model request plus its tool calls; turn = zero+ steps, opens at first claim, closes when nothing is owed (Ch 6)
- **StreamChunk** — closed 7-variant wire union (block-start/delta/block-end/usage/finish/…) adapters emit (Ch 17)
- **SurfaceEventType** — the only three message-producing log types: `user/message`, `assistant/message`, `tool/result` (Ch 12, 13)
- **TypertLookupMap** — wire↔object identity table for complex Host params crossing the Remote boundary (Ch 9)
- **Vendoring** — pinned source under `vendor/<dir>/`, published as a release member (Ch 19)
- **Waterfall veto** — returning without calling `next()` short-circuits the chain; observers must always call `next()` (Ch 4)
- **WebBootGraph** — composed module graph written to `window.__DSH_BOOT__` before parser-preloaded scripts (Ch 17, 18)
- **Whole-value event rule** — state-carrying log events carry complete post-change state, never deltas (Ch 16)
- **unwrapExports trap** — Loader prefers `exports.default`, dropping sibling `inject`/`name`/`Config` (Ch 21)
